# نظام المنجرة | Al-Manjara

**المنجرة** هو تطبيق مكتبي متكامل لإدارة ومحاسبة ورش النجارة وصناعة الأثاث والمطابخ، صُمم ليجمع بين بساطة الاستخدام وكفاءة الأداء اليومي؛ حيث يساعدك على متابعة طلبات العملاء ومراحل التصنيع خطوة بخطوة، وضبط المصروفات وحسابات الموردين والديون بدقة، مع إصدار الفواتير وسندات القبض وتقارير الأرباح والتدفق النقدي، ويعمل بشكل كامل وسريع دون الحاجة إلى إنترنت (Offline-first)، مع ميزة التحديث التلقائي الذكي لضمان استمرار عمل الورشة بأحدث التقنيات وأعلى درجات الموثوقية.
